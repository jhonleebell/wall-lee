Baixar o WALL-LEE Connect

Windows 0.62.31 e Android 0.71.2 — piloto externo controlado.

Antes de instalar. O Windows não tem assinatura comercial de editor; o APK usa o certificado atual de teste. Os sistemas podem exibir avisos de segurança. Use os arquivos desta release. O teste incluído verifica a integridade; SHA256 não autentica o editor.

Windows 0.62.31

Windows 10 (build 19041 ou posterior) ou 11, 64 bits. .NET incluído. WebView2 detectado automaticamente; o ZIP inclui o instalador oficial Microsoft para instalação com seu consentimento, usando internet.

Baixar para Windows
SHA256: CBF6D522C23E5BA5EEE3C35308735983B116413BA38C90882C6356E3F6311D97

Instalação: extraia numa pasta nova e execute TESTE-PILOTO-WINDOWS.cmd. Depois do resultado APROVADO, abra WALL-LEE Connect.exe. Se faltar WebView2, abra o aplicativo, autorize a instalação oficial e repita o teste.

Para atualizar, mantenha a pasta anterior e siga REQUISITOS.md da release para preservar sua sessão na mesma conta Windows. Não limpe os dados para resolver mensagens pendentes.
