Baixar o WALL-LEE Connect

Versão piloto. Baixe, confira o código e instale.

Antes de instalar. Estes instaladores são de laboratório e ainda não têm assinatura de produção, então o Windows e o Android vão mostrar um aviso de origem desconhecida. Confira o SHA256 abaixo para ter certeza de que o arquivo é o original.

Windows 0.62.27

Windows 10 ou 11, 64 bits. Pacote portátil, não precisa instalar o .NET.

Baixar para Windows
SHA256: BE34DCD03080B451F780A382B21798AB64E7FE939D02BB6BDDF466932929C483

Instalação: extraia o ZIP numa pasta nova e abra WALL-LEE Connect.exe. Para atualizar, extraia a versão nova em outra pasta e mantenha a antiga até conferir.

Android 0.71.0-whatsapp (71)

Android 8.0 ou mais novo.

Baixar para Android
SHA256: E1D7AE35BDFCEBE100AFCA191AD31361A8A20BA1766B7F0E96D36BBE0D478266

Instalação: abra o arquivo baixado e, se o Android pedir, permita a instalação de fontes desconhecidas para o navegador usado. Depois, abra o aplicativo e aceite o convite.

Como conferir o código

No Windows, abra o PowerShell e rode Get-FileHash caminho\do\arquivo -Algorithm SHA256. O resultado deve ser igual ao código mostrado acima.
